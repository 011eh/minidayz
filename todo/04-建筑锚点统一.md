# 04 - 建筑锚点统一

## 新约定

**建筑场景根节点原点 = Inside 地板贴图底边中心（bottom-center）。**

所有 `environment/building/*.tscn`（继承自 `buliding.tscn` 的建筑场景）已完成再锚定：根节点的每个直接子节点整体平移了 `-shift`，使 Inside 精灵实际矩形（节点 position + offset + 贴图尺寸）的底边中心落在根原点 (0, 0)。内部相对布局（碰撞、门、室内区域）未改变。

> **原版 dx/dy 换算**：原版地块模板槽位的 `dx/dy` 按旧锚点（约等于 Inside 左上角）定位。改为 bottom-center 锚点后，摆放同一位置需换算：
>
> **新槽位 position = 原版 (dx, dy) + 该建筑在下表中的 shift 值**
